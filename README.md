# Krusah English P.6 Hub (ครูสา) — คลังสื่อการสอนภาษาอังกฤษ ชั้น ป.6

เว็บแอปรวบรวมและจัดการสื่อการสอนวิชาภาษาอังกฤษ ประถมศึกษาปีที่ 6 ออกแบบให้ใช้งานได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์

## วิธีเปิดใช้งานทันที
1. ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดในเว็บเบราว์เซอร์ (Chrome / Edge / Safari / Firefox)
2. ใช้งานได้ทั้งแบบออฟไลน์ในห้องเรียน และออนไลน์ (สำหรับวิดีโอ YouTube หรือลิงก์ภายนอก)

## ฟีเจอร์หลัก
- **แบ่งตาม 6 หน่วยการเรียนรู้ (Unit 1 – Unit 6 & ติว O-NET ป.6)** พร้อมระบบค้นหา แยกตามประเภทสื่อ และบันทึกสื่อโปรด
- **ใบงาน / แบบฝึกหัด (Worksheets)**: ดูออนไลน์ เปิด/ซ่อนเฉลยสำหรับครู สั่งพิมพ์เป็นกระดาษ A4 ได้สวยงาม และรองรับการแนบไฟล์ PDF/รูปภาพจากเครื่อง
- **สไลด์และวิดีโอการสอน (Slides & Videos)**: มีสไลด์ขึ้นจอห้องเรียนพร้อมปุ่มขยายเต็มจอ เสียงอ่านประโยคตัวอย่าง และรองรับฝังวิดีโอ YouTube / Google Slides
- **บัตรคำศัพท์ & เกมจับคู่ (Flashcards & Match Game)**: พลิกการ์ด 3 มิติ มีเสียงอ่านภาษาอังกฤษ (ความเร็วปกติและช้า 0.7x) พร้อมเกมจับคู่คำศัพท์จับเวลา
- **แบบทดสอบออนไลน์ (Quizzes)**: ตรวจคำตอบทันทีพร้อมคำอธิบายเฉลยภาษาไทยและให้ดาวสรุปผลคะแนน
- **โหมดครู (Teacher Mode)**: เพิ่ม/แก้ไข/ลบสื่อการสอน จัดการหน่วยการเรียนรู้ แนบไฟล์จากเครื่อง ตั้งรหัส PIN ล็อกโหมดครู และสำรอง/นำเข้าข้อมูล (`.json`)

## วิธีนำเว็บไปฝากขึ้นออนไลน์ฟรีในอนาคต (เช่น Netlify Drop / GitHub Pages)
1. กดเข้า **โหมดครู** > **ตั้งค่า** > กด **ดาวน์โหลด `data.js` เวอร์ชันปัจจุบัน**
2. นำไฟล์ `data.js` ที่ดาวน์โหลดมาวางทับไฟล์ `data.js` เดิมในโฟลเดอร์นี้
3. อัปโหลดโฟลเดอร์นี้ทั้งหมด (`index.html`, `styles.css`, `data.js`, `app.js` และโฟลเดอร์ `assets/`) ขึ้น [Netlify Drop](https://app.netlify.com/drop) หรือ GitHub Pages ได้ทันที!
